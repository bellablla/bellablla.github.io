In this program, I started by defining functions for each letter of my name and of the word SOS.
In my function definitions, I specified the number of dots and dashes for the morse code of each letter. In my setup code, I defined the input in A9, which I connected my alligator clips to on the lilypadUSB.
I defined the output as the buzzer, which would, depending on if the alligator clip was connected or not, buzz my name or SOS.
In my loop code, I wrote that if the alligator clip was connected, the buzzer would buzz the morse code for each letter of my name. 
I then wrote that if the alligoator clip was not connected, the buzzer would buxx the omrse code for SOS.

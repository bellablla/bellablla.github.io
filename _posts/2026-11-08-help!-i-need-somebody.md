This program first defines functions for each letter of my name and of the word SOS.
The function definitions, specify the number of dots and dashes for the morse code of each letter. The setup code defines the input for A9, which connects to the alligator clips to on the Lilypad USB Arduino.
The program defines the output as the buzzer, which, depending on if the alligator clip is connected or not, buzzes either my name or SOS.
The loop code says that if the alligator clip is connected, the buzzer will buzz each letter of my name in morse code
If the alligator clip is not connected, the buzzer will buzz SOS in morse code.
